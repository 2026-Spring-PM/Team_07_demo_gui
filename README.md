## 실행 방법

### 로컬 실행

```bash
git clone https://github.com/2026-Spring-PM/team07-zombie-farm.git
cd team07-zombie-farm
bash scripts/build.sh
./build/main
```

`scripts/build.sh`는 실행 환경을 자동으로 판별해 `build/main` 또는 Windows 환경의 `build/main.exe`를 생성한다.

### Docker 빌드 확인

프로젝트 기본 Docker image는 다음을 사용한다.

```bash
chwoong/team_00_project:0.1.0
```

Docker 환경에서 빌드가 되는지 확인하려면 다음 명령을 실행한다.

```bash
docker pull chwoong/team_00_project:0.1.0
docker run --rm --platform linux/amd64 \
  -v "$(pwd):/workspace" \
  chwoong/team_00_project:0.1.0 \
  bash -c "cd /workspace && bash scripts/build.sh"
```

Linux에서는 다음 명령으로 Docker 안에서 빌드 후 게임 실행을 시도할 수 있다.

```bash
bash scripts/run.sh
```

이 게임은 GUI/OpenGL을 사용하므로 Docker GUI 실행에는 X11 설정이 필요하다. macOS에서는 XQuartz를 설정해도 OpenGL/GLX 호환 문제로 Docker 안의 게임 창 실행이 실패할 수 있으므로, macOS에서는 로컬 실행을 권장한다.

## 스토리
 
20XX년. 원인 불명의 좀비 바이러스가 전 세계를 뒤덮었다.
도시는 무너졌고, 문명은 붕괴했다.
 
당신은 감염된 동생을 데리고 외딴 폐농장으로 도망치는 데 성공했다.
막막함이 밀려오던 그때, 낡은 라디오에서 신호가 잡혔다.
 
*"살아있는 사람이라면 들어라. 나는 백신 연구자 Dr. Chen이다.
농장에 연구소를 지어라. 좀비 샘플을 모아라.
내가 반드시 백신을 완성시켜 보이겠다."*
 
희망이 생겼다. 하지만 시간이 없다.
동생의 감염은 매일 진행되고, 밤마다 좀비 떼가 밀려온다.
 
낮에는 농사를 짓고 자원을 모아라.
밤에는 던전에서 좀비 샘플을 포획하고, 밀려오는 좀비 떼를 막아라.
그리고 백신을 완성해 이 지옥에서 탈출하라.

## 집 (Farmhouse) — SPACE로 입장

| 키 | 기능 | 재료 |
|---|---|---|
| **K1** | 고기 조리 | 우유 ×1 또는 달걀 ×2 → 고기 +1 |
| **K2** | 음식 조리 | 작물 ×10 → 음식 +20~35 |
| **K3** | 식사 | 음식 -20, 고기 -1 → HP +10 (하루 1회) |
| **K4** | 응급처치 | 약재1 ×1 → HP +30 |
| **K5** | **Nap** (낮) | 낮 → 밤 전환 (방어전 없음) |
| **K5** | **Sleep** (밤) | 방어전 → 다음날 시작 |
| **K6** | 강아지 밥주기 | 강아지가 집에 있을 때만 표시 |

## 방어벽 보수와 강화

방어벽은 밤마다 좀비의 공격을 받아 Wall HP가 감소한다.

- 방어벽 초기 건설:
  - 건축 자재 1개 필요
  - Defense Lv.1
  - 최대 Defense HP 50
- 방어벽 강화:
  - 건축 자재 1개를 추가로 사용하면 최대 Defense HP가 50 증가한다.
  - 예: Defense Lv.2 = 최대 Defense HP 100, Defense Lv.3 = 최대 Defense HP 150
- 방어벽 보수:
  - 손상된 Defense HP는 gold로만 회복할 수 있다.
  - Defense HP 1 회복당 1 gold 필요
- 방어벽 강화 조건:
  - 현재 Defense HP가 최대 Defense HP까지 모두 회복된 상태에서만 강화할 수 있다.

예시:
Defense Lv.2 상태에서 현재 Defense HP가 70/100이라면, 먼저 30 gold를 사용해 100/100까지 보수해야 한다.  
그 후 건축 자재 1개를 추가로 사용하면 Defense Lv.3이 되고 최대 Defense HP가 150이 된다.

## 밤 - 좀비 방어

밤에는 매일 좀비 침공이 발생한다.  
생존 일수에 따라 좀비 수와 총 공격력이 증가한다.

| 생존 일수 | 좀비 수 | 총 공격력 |
|---|---:|---:|
| Day 1 | 1마리 | 5 |
| Day 2~4 | 3마리 | 15 |
| Day 5~9 | 5마리 | 25 |
| Day 10~16 | 7마리 | 35 |
| Day 17~25 | 9마리 | 45 |
| Day 26~36 | 11마리 | 55 |
| Day 37~ | 12마리 | 60 |

좀비 공격력만큼 Defense HP가 감소한다.
- 공격력이 현재 Defense HP보다 작거나 같으면 Defense HP만 감소한다.
- 공격력이 현재 Defense HP보다 크면 Defense HP는 0이 된다.
- Defense HP가 0이 되면 플레이어 HP가 감소한다.
- 플레이어 HP 감소량은 좀비 수 × 2이다.
- 초과 피해량과 상관없이 HP 피해는 고정 피해로 적용된다.

Day 12에는 좀비 7마리가 침공하며 총 공격력은 35이다.  
현재 Defense HP가 20이라면 공격 후 Defense HP는 0이 되고, 플레이어 HP는 14 감소한다.

## 던전 — 밤에만 입장

밤 게이트를 통과해 던전에 입장. 하루 1회 가능.

| 키 | 동작 |
|---|---|
| **WASD** | 이동 |
| **SPACE** | 공격 |
| **F** | 포획 미니게임 (기절한 좀비) |
| **ESC** | 던전 나가기 |

- 포획한 좀비 → **좀비 샘플** → 연구소에서 백신 개발에 사용
- 강아지 회복 후: 공격력 **+20%**

## 강아지 이벤트

던전을 처음 방문하고 돌아오면 다친 강아지 발견 이벤트가 발생한다.

1. **[Y]** 집에 데려오기 선택
2. 집 실내 **K6** 으로 고기 1개씩 주기
3. 총 **10개** 주면 완전 회복
4. 효과: 던전 공격력 +20%, 특수 엔딩 조건 달성

## 💡 알아두면 좋은 것들

- 게임 곳곳에는 공식적으로 안내되지 않은 것들이 숨어있다. 맵을 꼼꼼히 탐색하고, 다양한 시도를 해보자.
- 레벨업 시 골드 +100, MaxHP +10. 레벨업 화면이 뜨면 Enter로 계속.
- 음식이 부족하면 식사를 못 해 HP가 매일 조금씩 감소한다.
- 닭은 매일 달걀, 소는 매일 우유를 생산한다. 단, 사료(Food)를 소비한다.
- 성벽 HP가 0이 되면 플레이어가 직접 피해를 받는다. Gold로 수리하고, 자재로 업그레이드하자.

## Docker / macOS 참고

- Docker 안에서 `bash scripts/build.sh`가 성공하면 과제 기본 Docker 빌드 환경은 만족한다.
- macOS에서 Docker GUI 실행이 `GLXBadContext` 또는 `No matching fbConfigs or visuals found` 오류로 실패할 수 있다.
- 이 경우 코드 빌드 문제라기보다 XQuartz/OpenGL 호환 문제이므로 macOS에서는 `bash scripts/build.sh` 후 `./build/main`으로 로컬 실행한다.
